# NeoEssentials Commands

## Player Commands

### Teleportation
- `/home [name]` - Teleport to your home
- `/sethome [name]` - Set a home location
- `/delhome <name>` - Delete a home
- `/homes` - List your homes
- `/spawn` - Teleport to spawn
- `/back` - Return to previous location
- `/tpa <player>` - Request to teleport to a player
- `/tpaccept` - Accept a teleport request
- `/tpdeny` - Deny a teleport request

### Warps
- `/warp <name>` - Teleport to a warp
- `/warps` - List available warps

### Economy (if enabled)
- `/balance` - Check your balance
- `/pay <player> <amount>` - Pay another player
- `/baltop` - View richest players

### Messaging
- `/msg <player> <message>` - Send private message
- `/reply <message>` - Reply to last message

## Admin Commands

### Teleportation
- `/tp <player>` - Teleport to a player
- `/tp <player1> <player2>` - Teleport player1 to player2
- `/tphere <player>` - Teleport a player to you
- `/setspawn` - Set server spawn location

### Warps Management
- `/setwarp <name>` - Create a warp
- `/delwarp <name>` - Delete a warp

### Moderation
- `/kick <player> [reason]` - Kick a player
- `/ban <player> [reason]` - Ban a player
- `/tempban <player> <time> [reason]` - Temporarily ban a player
- `/unban <player>` - Unban a player
- `/mute <player> [time] [reason]` - Mute a player
- `/unmute <player>` - Unmute a player

### Economy Management
- `/eco give <player> <amount>` - Give money to a player
- `/eco take <player> <amount>` - Take money from a player
- `/eco set <player> <amount>` - Set a player's balance

### Server Management
- `/broadcast <message>` - Send message to all players
- `/neoessentials reload` - Reload configuration files
