# NeoEssentials Server Showcase

This page highlights servers that are using NeoEssentials in creative and effective ways. Get inspired by these examples or submit your own server to be featured!

## Featured Servers

### ZeroG Network

![ZeroG Network](../images/servers/zerog_network.png)

**Website:** [zerog-network.com](https://zerog-network.com)  
**IP Address:** `play.zerog-network.com`  
**Version:** 1.21.1  
**Player Count:** 100-250 players online  

ZeroG Network is a survival-focused server network that utilizes NeoEssentials to create a seamless player experience across multiple server instances. Their implementation showcases:

- Custom tablist with server status information
- Advanced economy system with shop integration
- Unique warp system with custom warp categories
- Extended kit system for player progression

**What makes it special:** ZeroG Network has created custom extensions for NeoEssentials that add server-specific features while maintaining compatibility with the core mod.

## Submit Your Server

Would you like your server to be featured in our showcase? Submit your server by providing the following information:

### Submission Requirements

1. **Server Name**: The name of your Minecraft server
2. **Website**: Your server's website URL
3. **IP Address**: The server address players use to connect
4. **Version**: Minecraft/NeoForge version your server runs on
5. **Player Count**: Average player count range
6. **Description**: A brief description of your server (100-200 words)
7. **NeoEssentials Usage**: Details of how you use NeoEssentials (custom configurations, extensions, etc.)
8. **Screenshots**: 2-3 high-quality screenshots showcasing NeoEssentials features on your server
9. **Server Logo**: Your server's logo (if available)

### How to Submit

Send your submission to one of these places:

- **Discord:** Join our [Discord server](https://discord.gg/dUGAQF2Mga) and use the #server-showcase channel
- **GitHub:** Open a pull request adding your server to this page
- **Email:** Send your submission to showcase@neoessentials.net

Our team will review your submission and, if approved, add your server to this showcase.

### Showcase Guidelines

- Your server must be publicly accessible
- You must be using NeoEssentials in a meaningful way
- Your server must comply with the Minecraft EULA
- We reserve the right to remove servers from the showcase at any time
