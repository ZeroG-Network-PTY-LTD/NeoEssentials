How to set up Dropbox:
1. Go to dropbox.com/developers/apps
2. Create an app → Scoped access → Full Dropbox
3. Under Permissions, enable: files.content.write, files.content.read, files.metadata.read
4. Under Settings, click Generate access token and paste it above

How to set up Google Drive OAuth2:
1. Go to Google Cloud Console → APIs & Services → Credentials
2. Create OAuth 2.0 client ID (Desktop application)
3. Enable the Google Drive API
4. Use OAuth Playground or a script to exchange for a refresh token with scope https://www.googleapis.com/auth/drive.file
